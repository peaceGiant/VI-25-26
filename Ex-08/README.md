## Exercise 8 – Naive Bayes Classifier

### Task 1 – Car Acceptability Classification

You are given a dataset of cars consisting of categorical attributes.  
Split the dataset into training and testing subsets in a 70%–30% ratio.

Train a classifier that determines whether a given car is acceptable or not using the first 70% of the samples, and then compute the accuracy on the remaining 30%.

From standard input, read a new sample for which you need to determine the class it belongs to and print the result to standard output.

### Task 2 – Diabetes Classification

You are given a dataset containing information about blood glucose levels and blood pressure, consisting of continuous attributes.  
Split the dataset into training and testing subsets in a 70%–30% ratio.

Train a classifier that predicts whether a person has diabetes or not using the first 70% of the samples, and then compute the accuracy on the remaining 30%.

From standard input, read a new sample for which you need to determine the class it belongs to and print the result to standard output.
